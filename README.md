# AI Working

个人 AI 工作流与设计资产库。

本仓库用于保存获准个人保留的设计 Skill、模板、参考资料和可复用工作流。它不保存账号凭证、Token 或连接配置。

## 使用方式

1. 从 `skills/` 选择与任务相符的 Skill。
2. 提供需求、约束、可公开使用的参考资料和期望交付物。
3. 按 Skill 的阶段推进；每个阶段保留人工判断与决策记录。

## 结构

- `skills/`：可由 Codex 或其他 Agent 使用的流程说明。
- `knowledge/`：个人可维护的参考、案例和模板。
- `templates/`：通用交付模板。
- `docs/`：迁移状态、来源和使用边界。

详见 [资产迁移清单](docs/asset-migration.md)。
