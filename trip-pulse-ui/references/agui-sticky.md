# AGUI 上滑吸顶状态

新增 Figma 来源：文件 `i5rRhzNFvaaIXTXP65Yxwk`，节点 `2416:15806`，画板 **375 × 812px**。已通过 Figma MCP 读取设计上下文、图层元数据、变量及截图。该画板展示上滑后的吸顶状态，不是 AGUI 初始长页的替代。

## 可见规则

- 顶部保留 iOS 状态栏、返回与居中的 Trip.Pulse 小型 Logo；原始大 Logo 与页面引导文案已离开可视区。
- 内容从顶部导航下方开始滚动，参考画面中是三图拼接的花期活动卡。可见卡宽约 **335px**，左右边距约 **20–21px**，圆角约 8px，卡间约 12px。
- 顶部固定区域到约 **106px**，内容从其下方进入可视区。吸顶时应保持背景不透明，使滚动内容不会透出导航文字。
- 卡片标题使用 `Heading/L`：20px、粗体 700、行高 1.25；正文 `Body/M`：14px、行高 1.5。主文字 `#121826`，次文字按 TDS 语义色。
- 背景从 `#FFF4E4` 向白色过渡。该状态画板中语音输入实例位于可视画板之外，不能仅凭图层存在就把它强制显示在这个 812px 截图内。

## 交互转换

从 AGUI 初始长页滚动后，大型品牌区离开视窗，顶部切换为小型居中 Logo 的吸顶导航。具体触发阈值并未在静态画板中定义；实现时以大型品牌区完全离开可见区为合理触发点，并在验收说明中标为行为推断。滚动位置、导航固定和返回顶部应能通过真实 HTML/CSS/JS 实现。
