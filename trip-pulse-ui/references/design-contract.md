Trip.Pulse 页面色：奶白 `#FFF4E4`、品牌橙 `#C74401`、浅橙边框 `#FFCAB0`、Hot 标签边框 `#FFC8C0`、趋势卡边框 `#FFE2BB`。在 HTML 中集中定义为 `--pulse-*`，不可仅因数值相同就把品牌橙解释为“警告”。

常用间距：2 / 4 / 8 / 12 / 16 / 20px。常用圆角：2 / 4 / 8 / 12px 与全圆角。两个参考画板均以 375px 宽度、左右约 20px 内容边距为基准。MD 内容卡以边框和分割线区分；AGUI 底部输入组件有轻微的 TDS 阴影，因此不能把“全页禁止阴影”当作通用规则。

附件写明 TDS 字体为 Trip Geom；AGUI Logo 的 Figma 输出另显示 Avenir Black。独立 HTML 只有在提供可用字体文件时才能保证字体一致；否则用系统字体兜底，并标注该差异。深色模式未由这些来源定义，不要自行宣称符合官方深色规范。

## 一比一验收口径

- 固定 375 × 812px **可见视窗**。AGUI 长内容按原稿自然纵向滚动，不能缩小整页以塞进 812px。
- 对照原稿检查首屏、关键模块和底部状态，不只检查颜色变量。
- Figma 图片、Logo、图标是视觉还原的一部分。截图可以作为对照页，但不能替代可编辑的 HTML 结构；新功能页要用真实 DOM 和可用素材重建。
- 原稿没有提供的功能，不存在“像素级原稿”；需要按已确认的设计语言延展，并清楚说明是延展设计。
