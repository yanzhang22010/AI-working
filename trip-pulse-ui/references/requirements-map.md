# 功能清单映射

生成前把每项功能对应到：可见入口、页面反馈、空/加载/错误状态。只选择与任务有关的模块。

| 功能 | 主要模式 | 常见界面处理 |
|---|---|---|
| 热点、地点浏览 | MD | 趋势条、地点选择、筛选和列表 |
| 个性化推荐 | AGUI | 引导文案、结构化结果卡和理由 |
| AI 提问、追问 | AGUI | 底部输入区、`You may also ask` 问题卡 |
| 语音提问 | AGUI | `Hold to Speak`，需说明原型是否真的录音 |
| 行程、预算、比较 | AGUI 或组合 | 分天行程、预算摘要、比较卡 |
| 保存、分享、导出 | 任一模式 | 显式操作及成功/失败反馈 |
| 预订、支付 | 任一模式 | 核对与跳转边界，不伪造完成状态 |

一张页面应围绕主要任务组织信息，不能把功能清单拼成互不关联的组件展板。
